# Web Grupo Novo - Cronograma y Propuesta Institucional

Plataforma de seguimiento y cronograma de ejecución acelerada para el desarrollo de la nueva web institucional de **Grupo Novo** (Fiat, Jeep, RAM, Peugeot, Citroën, Leapmotor).

## 🚀 Despliegue en la Web (GitHub Pages)

Este proyecto está construido con HTML5 y Tailwind CSS (CDN), por lo que es 100% estático y compatible con **GitHub Pages**.

### Estructura de Archivos
- `index.html`: Página principal de visualización del cronograma y visión estratégica.
- `cronograma_grupo_novo.html`: Copia de respaldo del cronograma.
- `img/`: Recursos gráficos y logos de Grupo Novo en formatos SVG y PNG.
